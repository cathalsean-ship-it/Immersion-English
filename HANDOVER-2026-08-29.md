### `4c73704` — the redirect loop

`netlify.toml` carried one rule intended to strip trailing slashes:

```toml
[[redirects]]
  from = "/*/"
  to = "/:splat"
  status = 301
```

The diagnosis in yesterday's handover was close but not quite right, and the difference matters. Netlify normalises the trailing slash off the `from` pattern, so the rule was really `/*` to `/:splat` — **every path redirecting to itself**. Real pages were unharmed because a non-forced rule does not shadow a file that exists. Missing pages had nothing to shadow and looped until the browser gave up.

Which means the trailing-slash canonicalisation you can observe on production (`/contact` 301s to `/contact/`, which returns 200) was **never coming from that rule**. It is Netlify's own pretty-URL handling and deleting the rule does not touch it.

`netlify.toml` now holds no rules and a comment explaining why, plus what to curl before adding one. `src/pages/404.astro` builds to `dist/404.html`, which Netlify serves with a 404 status. `BaseLayout` gained an optional `noindex` prop, default false, set only by the 404 page — Netlify serves `/404` at 200 as an ordinary page, so without it that page could be indexed on its own.

**After deploying, curl a real page and a missing one, and check the status AND the `Location` header on both.** That is the whole verification.

Expect a batch of URLs in Search Console to move from "Redirect error" to "Not found (404)". That is the backlog clearing, not new damage.

### `5bf2e3f` — the 90 minutes

Every lesson and session is 90 minutes. The site said so in a bullet on three cards out of six and nowhere else, so "€45 per lesson" read as an hourly rate and the courses looked about a third dearer than they are.

`lessonMinutes` and `unitNoun` are now **required** fields on `Course`. A course cannot be added without stating how long it runs, and the duration renders into the rate itself — "€45 per 90-minute lesson", "€60 per 90-minute session" — on the lessons page, the corporate page, in `llms.txt` and in the JSON-LD.

Two things were found on the way and fixed:

- **`BaseLayout`'s JSON-LD carried a €45 price for the Personal Speaking Coach while the page charged €50.** That block is emitted on every page, so Google has been reading a price the site does not charge. It renders from `courses.ts` now, as does Speak Up!'s €290.
- **`corporate-training.astro` held €60 and €540 twice** — once in the visible price block, once in its own JSON-LD — with nothing keeping them in step. Both render from `courses.corporateTraining` now, which the existing build-time guard covers: 10% off 10 x €60 is €540, so a wrong package price fails the build.

€60 is deliberately above the €45 individual rate for the same 90 minutes. There is a comment in `courses.ts` saying so, because it looks like an error and is not.

The Speak Up! card was left alone by instruction — its bullets already state the length. Two cards that stated 90 minutes in both a bullet and the new price label had the bullet trimmed to "Online sessions", which is what it alone carries.

### 2. The site disagrees with itself about trailing slashes

New, and it is the real indexing issue on this site. Four places, two answers:

| Where | Says |
|---|---|
| `astro.config.mjs` | `trailingSlash: 'never'` |
| Canonical tag on every page | `https://immersion-english.com/contact` |
| `public/sitemap.xml`, all 17 URLs | `https://immersion-english.com/contact` |
| What production serves | `/contact` 301s to `/contact/` |

So every canonical tag and every sitemap entry points at a URL that redirects, and the only URLs returning 200 are the ones the site says are *not* canonical. Google generally untangles this, but it is a weak signal on every page and a sitemap full of redirects.

Two ways out, opposite directions:

- **Change the URLs to match the signals** (`build.format: 'file'`) — `/contact` starts serving 200 directly. Every currently-indexed `/contact/` becomes non-canonical. Real churn.
- **Change the signals to match the URLs** — emit trailing-slash canonicals and sitemap entries. No URL changes at all.

**The second is the safe one.** It changes no URL; the site just stops contradicting itself.

## Things that will confuse you

**Netlify rewrites form tags at deploy.** Unchanged from yesterday: normalise the opening form tag before diffing `dist/` against live or you will chase a ghost.

**Alt text can be wrong while the code looks perfect.** Unchanged. If you touch image metadata, open the images.

**The comments in `dublin.ts` and `courses.ts` are load-bearing.** They record why things were removed and what must not come back. `courses.ts` now also records why corporate is €60 and why `lessonMinutes` is required. Read them before changing the data they guard.

**Astro can drop the space between an expression and a following tag.** On `corporate-training.astro`, a price of the form `€{expression} <span>` compiled to `€60<span>` — the space in the source vanished from the output — while the identical pattern on `lessons.astro` kept it. Write an explicit space expression when a space sits between an expression and a tag, and check the built HTML rather than the source.

**`dublin-overview-copy.md` is superseded in places** and now carries a warning banner listing exactly which lines are false — including three separate claims that the group leader flies out from Sofia, which he does not. It is kept for its voice and structure, not its facts. Do not copy from it without checking `dublin.ts`.

**`.claude/` is gitignored**, so `launch.json` for the dev server is not in the repo. Port 4321 collides with another project on this machine; the Astro dev server was run on 4330.
